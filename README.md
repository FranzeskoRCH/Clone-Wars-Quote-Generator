## Star Wars: The Clone Wars Quote Generator

Aplicación web para explorar y generar frases de *Star Wars: The Clone Wars*. Permite descubrir frases, buscar y filtrar por temporada, consultar detalles, guardar favoritas y compartirlas. La interfaz incluye una animación de hiperespacio al generar una frase.

La aplicación está construida con React, TypeScript, Vite y Tailwind CSS. Obtiene las frases de una API Flask desplegable por separado.
